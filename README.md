# Job Vacancy System (JS)

Console-based job vacancy management system that runs entirely through browser prompt/alert dialogs.

## Features

- Menu-driven interface with 6 options
- Create vacancies with name, description, deadline
- List all registered vacancies
- View individual vacancy details
- Apply for a vacancy (store candidate name)
- Delete vacancies with confirmation
- Input validation for array indices

## Tech Stack

- Vanilla JavaScript
- HTML5 (minimal shell page)

## Usage

Open `index.html` in a browser. The entire interface runs via `prompt()`, `alert()`, and `confirm()` dialogs — no DOM rendering.

Visit the [live demo](https://tomas-barros1.github.io/Job-vacancy-system-JS/).
